# ForestFireSimulation
Forest fire simulation in MATLAB

Course: Computer Modeling and Simulations

Project: Forest Fire Simulation

A MATLAB simulation of forest fire spread using a 2D grid model. Each cell represents a tree that can be empty, alive, or burning. The simulation demonstrates stochastic modeling and cellular automata in environmental systems.

Overview

This project simulates the spread of forest fires using MATLAB. The simulation models a forest as a 2D grid, where each cell represents a tree that can be in one of several states:

Empty

Tree

Burning

The model demonstrates how fire spreads over time based on probabilistic rules and environmental parameters. This project is intended as a practical demonstration of stochastic modeling and cellular automata in environmental simulations.
